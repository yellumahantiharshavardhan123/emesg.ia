# E‑MESG

Realtime chat + groups + vibes (status) built with React + Vite + Tailwind + Supabase.

## Quickstart

- Copy `.env.local.example` to `.env.local` and verify Supabase URL and anon key
- Install deps: `bun install` (or `npm install`)
- Start dev: `bun dev` (or `npm run dev`)

## Tech
- React + TypeScript + Vite
- TailwindCSS (glassmorphism theme)
- Framer Motion
- Lucide Icons
- Supabase (Auth, Postgres, Realtime, Storage)
- Hosting: Vercel

## Scripts
- `dev` — run Vite dev server
- `build` — build for production
- `preview` — preview production build

See `DEPLOYMENT.md` for full deployment steps (Vercel + Supabase setup).
